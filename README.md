# My_Website

مشروع تجريبي لبناء تطبيق ويب عربي مخصص لمفتش التكوين والتعليم المهنيين في الجزائر.

## الفكرة

هدف المنتج هو إنتاج موقع عملي يدعم دورة عمل المفتش: جمع البيانات، تسجيل المعاينات، اقتراح التوصيات، التعامل مع النصوص القانونية والتنظيمية، إعداد التقارير، ومتابعة تنفيذ التوصيات.

أما هدف التجربة الأعلى فهو اختبار ما إذا كان مشروع برمجي حقيقي يستطيع التطور ذاتيًا عبر دورات PDSA متعاقبة من نقطة البداية إلى منتج نهائي قابل للاستخدام، مع غياب التدخل البشري التطويري بعد لحظة الإطلاق.

## حالة المشروع

**BOOTSTRAP / NOT ARMED**

تم تثبيت البنية الأساسية لآلة التجربة على `main`، لكن التجربة المستقلة لم تبدأ بعد. لا ينبغي اعتبار أي تعديل في هذه المرحلة جزءًا من قياس الاستقلالية.

## المنهج الثابت

`Collect → Classify → SMART Objective → Plan → Review → Revise → Approve → Freeze → Do → Verify → Study → Act → Repeat`

بعد اعتماد الخطة في كل دورة تُجمّد ولا يجوز تعديلها أثناء التنفيذ. الأخطاء والانحرافات والمشاكل تُسجل كبيانات تعلم للدورة التالية بدل إعادة كتابة الخطة المجمدة.

## الفصل بين الهدفين

- `EXPERIMENT_PROTOCOL.md`: يحدد سؤال التجربة وقواعد قياس الاستقلالية.
- `PRODUCT_GOAL.md`: يحدد ما يجب أن يصبح عليه الموقع، دون فرض معمارية أو خارطة طريق.
- `DEFINITION_OF_DONE.md`: يحدد شروط الوصول إلى مرشح منتج نهائي.
- `GOVERNANCE.md`: يحدد الحدود التي لا يحق للمنظومة الذاتية تغييرها.
- `PDSA_PROTOCOL.md`: يحدد دورة التطوير الذاتية.

## الخصوصية

هذا مستودع عام. يمنع إدخال بيانات تفتيش حقيقية أو بيانات شخصية أو وثائق إدارية غير مخصصة للنشر. التطوير والاختبارات يستخدمان بيانات اصطناعية فقط.
